# Wellmanifest Legal Lifecycle

Experimental, location-aware standard for licenses, legal policies and
jurisdiction rules used when creating or operating products and services.

The normative artifacts live in `standard/`; architecture and lifecycle
guidance live in `docs/`. This repository is not legal advice, does not store
personal data and never grants execution or billing authority.

It composes with `wellmanifest/product-lifecycle` and can be referenced by
`wellmanifest/saas-lifecycle` through versioned `legalPolicyRef` and pack
bindings.
